# 🏎️ Porsche Panamera — Interactive Gallery

A clean, dark-themed interactive gallery showcasing different **Porsche Panamera** models. Built with a luxury aesthetic in mind, featuring smooth card expansion animations, subtle gold gradients, and a glowing neon badge.

---

## ⚡ What’s inside

* **Interactive Cards:** Click on any card to expand it and reveal detailed specs (uses vanilla JS for toggling state).
* **Sleek Visuals:** Dark mode layout with gold accent colors (`#d4af37`), CSS glow effects, and gradient typography.
* **Responsive Layout:** Automatically switches from horizontal cards on desktop to a vertical stack on mobile screens.
* **Modular Code:** Separated into simple `index.html`, `style.css`, and `script.js` files.

---

## 🛠️ Built with

* **HTML5**
* **CSS3** (Flexbox, CSS animations, gradient clips)
* **JavaScript** (Vanilla ES6)
* **Google Fonts** (*Montserrat*)
